# GitHub Pages

This repository is prepared to run directly from the repository root on GitHub Pages.

Pages settings:
- Source: Deploy from a branch
- Branch: `main` (or the branch containing this project)
- Folder: `/ (root)`

The root `index.html`, `app.js`, `styles.css` and `cesium.html` are the GitHub Pages publishing surface. The `web/` copy is retained as the organized web source for local development/maintenance.
