# Fuentes abiertas / oficiales

- Catastro: OVC no-protected data + INSPIRE WMS/WFS/ATOM.
- Generalitat de Catalunya: MUC / Planejament WMS-WFS y descargas de planeamiento.
- ICGC: ortofoto y futuras capas de elevación/LiDAR.
- OpenStreetMap: actividades/POI.
- OpenFreeMap: mapa base sin cuenta/API key.
- Overture Maps: edificios/lugares abiertos por descarga de área.
- Ollama: IA local opcional, sin API externa.
